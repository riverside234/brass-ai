# B04: native search_v1 teacher collection and labels

2026-10-29. **Implemented; lab qualification Pending.** The source supplement and qualification commands are in [distribution/rust-lab-b04](../distribution/rust-lab-b04/README.md). The installed game, historical archives and production training state were not modified.

## Native search and evidence

The additive collector links the exact B01 source in a detached build directory. A small, source-checked overlay enables read-only final-watermark exports in `Session`, without changing selection, backup, tournament quotas, complete-plan support, recommendation ranking or finalization. Ordinary/default sessions allocate no export state. Both the base fingerprint and the actual modified core fingerprint are recorded separately from the B04 producer hash; no old source receipt is relabeled.

At retirement the exporter copies root statistics and, when selected, the second action's node statistics with its full typed information key. No arena or tree is retained. Actual successor equality includes observer, legal order, revision, recall, public state, model, reward, context and causal ledger. An invalid continuation discards the snapshot and replans under the same original allowance. Only the validated node can yield a continuation label, once.

The target calls the search's own float64 `Statistics::policy`; it uses all completed trajectories, including a partial halving round. Recommendations continue using the completed-round snapshot. Root, continuation and replanned-root exports include logits, absolute-seat actor value/returns, counts, mixed value, target, N/K, watermarks, completed rounds, played move/support/fallback, draws, deadlines and overrun. Continuations report the original root's effective K and legal width; they do not invent a second tournament. No-evidence, forced and sub-stage decisions yield no labels. Valid fallback-played and late-finalized evidence survives; cancellation and stale/non-finite/wrong-owner replies cannot publish.

The native lane owns the complete authoritative game, hidden deck progression, observation/recall, legal choices, insolvency ledger, search and feature encoding. All four seats use the frozen learner. Reserved turns come from the existing dedicated teacher stream; other decisions sample its raw T=1, epsilon=0 policy. No ordinary branch/opening exploration or legacy rollout opponent is introduced. Raw teacher results never become ordinary replay, PPO behavior probabilities, critic/PPG rows, auxiliary scoring data or ratings.

## GPU boundary and lifecycle

One session, one thread, one pending path and the exact 4s/K16 profile are enforced at Python and native admission. The existing GPU scheduler, shared slots, frozen model cache, batching and CPU admission are reused. An optional raw-logit request adds a float32 output alongside the existing policy/utility heads, including the full-candidate chunked path. Ordinary calls keep their existing output path. Native-to-Python leaf requests carry bounded binary tensors plus explicit job/model/export/epoch/revision/observer/legal/context bindings, rather than game-state RPCs.

Python drains an expired/cancelled GPU envelope before allowing owner reuse and suppresses its predictions. A 30-second stuck GPU/native watchdog retires the failed table; unpublished rows from an incomplete table cannot enter the buffer. Ordinary deadline expiry uses the existing bounded native fallback and preserves completed evidence. A physical stuck-device failure is a failed qualification, not a shorter game accepted as equivalent work. Cancellation between actions kills the owner, not just its pending label.

GPU timed quotas are calibrated on the actual device using eight completed trajectories at each of two admitted action roots. The conservative measured cost includes encoding/queue/forward/finalization and is bound to model, checkpoint export, reward, source, device and profile. Each tournament freezes N from the remaining original work allowance. Action two, retries and replans cannot create a new 4-second clock. Calibration probes are explicitly diagnostic and are rejected by teacher-buffer admission.

## Trainer and readiness boundaries

The explicit collector/barrier routes teacher jobs first and returns ordinary results through a separate callback. Existing disabled legacy teacher/V4 switches remain inert. `off` dispatches no jobs or term; shadow/on use the new route and never the legacy wall-fraction or work-budget fields. The retained historical consumer keeps its existing allowance formula and telemetry. The production training entry point still blocks live shadow/on until B05/B07 qualify updates and adoption.

Latest non-null current-reward readiness, explicit not-ready deferral, usable existing buffer in on mode, and narrow mode/share receipt preservation are retained. The lab runner can resolve pre-adoption readiness from consecutive retained, hash-checked committed checkpoints; it stops at missing history or a reward boundary. It does not skip an explicit false receipt or use the local g890 exception. The original model calibration field is not rewritten. The new native teacher producer participates in buffer identity, so old producers cannot silently supply new labels.

Reviewed source transitions preserve the existing joint7 recipe and complete learner/optimizer/RNG/PPG lineage. B04 does not commit a production source transition, enable training teachers, or run an optimizer step. B03's full-state restore checks remain separate; B05 covers next-update/commit/resume, and B07 covers rollout.
