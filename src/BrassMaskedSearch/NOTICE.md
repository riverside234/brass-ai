# Masked ISMCTS

The authored C# port adapts ISMCTS/PUCT mechanics from OpenSpiel, Copyright 2019
DeepMind, licensed under Apache-2.0. See `LICENSE-OpenSpiel`. The reference pin is
in `configs/references/masked-ismcts.lock.json`. Rules, legal masking, independently
masked opponents, v3 scoring, clock and completed-turn safeguards are project code.
